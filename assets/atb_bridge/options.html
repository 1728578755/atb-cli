「重新加载扩展」会中断正在执行中的命令；CLI 侧会看到一次超时重试。

daemon 连接

-
插件端口
扩展通过该端口连本机 daemon，默认 18765。18767 是 API 端口，不能混用。
访问 token
设置后 daemon 只接受带 token 的连接。推荐 atb trust-extension --token 生成并写入两端。
信任档位
兼容档接受未带 token 的连接，任何本机进程都可能接管浏览器；严格档要求 token 匹配。

改了不生效怎么办

  1. 确认 CLI 与扩展用的是同一个端口：atb status 里的 extension.port 应与这里一致。
  2. token 档下两端必须一致，改完一侧要同步另一侧。
  3. 仍然连不上时，先「重新加载扩展」，再看诊断页的「最近一次连接错误」。

Profile Label

给人看的名字，不是标识符

多浏览器 / 多 Profile 时用它区分。需要跨 Profile 唯一性校验时用 atb profile label。

标识

只读
browserId-
profileId-
extensionId-

这些标识用于 CLI 选择标签页/Profile，属于本机环境信息，不要贴到公开渠道。

标识跨重载保持不变是刻意的：会话 key 由 browserId + profileId 拼成，一换，CLI 里的默认浏览器与 @e 引用就全部失联。只有在「整份浏览器 profile 被克隆到另一台机器、两个实例撞同一个 id」时才需要重置。
