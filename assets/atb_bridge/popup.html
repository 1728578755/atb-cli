Cookies

-
    点「刷新」读取当前站点的 cookies。值默认打码，仅在本机显示。

    复制会写入系统剪贴板，并按上面的时长自动清除；关闭弹窗立即恢复打码。

    连接

    设置后 daemon 只接受带 token 的连接。推荐用 atb trust-extension --token 生成并写入两端。

    身份

    多浏览器 / 多 Profile 时用它区分。需要跨 Profile 唯一性校验时用 CLI 设置。

    界面

    宽度与间距只影响工具栏弹窗；在标签页里打开时按页面宽度自适应。

    调试注入

    默认值

    --persist 的默认过期时间；永久驻留需 CLI 显式确认。

    后台标签页：默认开；
    ATB_HIDDEN_TAB_WARNING=off 关闭。

    console：atb console history --settle-ms 300
    或 ATB_CONSOLE_HISTORY_SETTLE_MS。

    management 权限只用于列出已安装扩展；在管理页「关于 → 高级权限」由你手动授权。

    维护

    改了 manifest、或在 chrome://extensions 里看到报错时，先重新加载扩展。
